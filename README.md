# OpenANC 🎧

Aplicativo Android experimental de antirruído usando microfone e fones com fio. A inversão da onda captada **não garante ANC eficaz**, pois o cancelamento no ouvido depende de latência e resposta acústica não medidas.

## APK

Abra **Actions → Gerar APK Android** para obter o APK de depuração, depois que o projeto estiver publicado.

## Segurança

Use volume baixo. Interrompa ao perceber apitos, ressonâncias ou amplificação de ruído. Não utilize em trânsito ou situações que exijam escutar alertas.
